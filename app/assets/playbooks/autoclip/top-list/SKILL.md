# Top N list

A recipe, not rules: the user's request wins.

- **Hook (0–2 s):** promise the payoff and the number — "5 … you'll wish you knew sooner". Show the number big.
- **Items:** 3–7 items (default 5). Each item is one scene: the rank number huge, a 2–6 word title, then ONE concrete
  detail (a figure, a name, a before/after). No filler sentences.
- **Order:** count down to #1, or up if the items build on each other. Keep the strongest item for last and tease it
  early ("… and #1 surprised me").
- **Rhythm:** every item roughly the same length; a hard cut or a quick wipe between items; the rank number animates in
  first, the detail lands on its word.
- **Consistency:** the same layout for every item (number position, title position) so viewers track progress; a small
  progress marker (1/5 … 5/5) helps retention.
- **End:** a one-line recap or the call to action; no long outro.
